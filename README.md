# GhaziLang

[![License: Commercial / Source-Available](https://img.shields.io/badge/License-Source--Available-blue.svg)](LICENSE.md)

Official compiler and language core for GhaziLang — a universal, general-purpose programming language built for GhaziOS and cross-platform development.

## Overview
GhaziLang is designed for high performance, memory safety, and seamless system-level integration across platforms.
